# Diamond Bank Website (Fictional Demo)

A multi-page website for a made-up bank, built as a personal project to practise web development. **Diamond Bank is not a real bank**, and nothing on this site is real banking information.


## Pages and features
- Homepage with a navigation menu, search box and an image slider with previous/next buttons
- Business, Private Banking, Personal and International Banking pages
- Sign-in form 


## Built with
- HTML
- CSS
- JavaScript (image slider)

## What I learned
- Building a multi-page website with consistent navigation, header and footer
- Using JavaScript to make the image slider work
